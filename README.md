# Collections Java API

Exercícios da trilha de Java da DIO (2023) sobre a Collections API.

| Pacote | Conteúdo |
|---|---|
| `list` | operações básicas (carrinho de compras, lista de tarefas), pesquisa (catálogo de livros, soma de números) e ordenação com `Comparator` |
| `set` | operações básicas (convidados), pesquisa (agenda de contatos) e ordenação (produtos por preço) |
| `map` | operações básicas (agenda), pesquisa (estoque de produtos) e ordenação (agenda de eventos) |

Cada pacote tem uma classe `Main*` para executar os exemplos.

Projeto arquivado — mantido como registro de estudo.
